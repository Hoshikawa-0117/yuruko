# ゆるこ 公式アプリ

友だちと作る「一番くじ」みたいなくじの会社「ゆるこ」の、最新情報アプリ。
OHinasamaとは別ブランド。構成はOHinasamaショップと同じ「HTML1枚＋Supabase（リアルタイム）」。

ゆるこ＝顔が大きく、目などの部位が小さい可愛いキャラクター（左上のマークは仮のSVG）。

## ファイル
| ファイル | 役わり |
|---|---|
| `index.html` | アプリ本体（さわらなくてOK） |
| `data.js` | 設定。パスワード・Supabase接続先・最初のサンプルデータ |
| `docs/sql/001_yuruko.sql` | **パパがSupabaseのSQL Editorで1回実行する**（OHinasamaと同じプロジェクト） |
| `docs/logo_font_preview.html` | ロゴのフォント候補15種＋色4案 |

## 画面（お客さん側）
ホーム（いちおしくじ・くじ・最新ニュース）／くじ一覧（発売中・近日・終了で絞り込み）／お店／ニュース
くじをタップ → 全体写真・PRIZE一覧（S PRIZE が金色でいちばん上）・賞ごとの写真・のこり個数。写真はタップで拡大。

## スタッフページ（右上の🔒）
パスワード（data.js の adminPassword、初期値 yuruko1234）を入れると開く。できること：
- 🎫 くじを追加（第○弾・状態・値段・日にち・場所・色・絵文字・全体写真・賞S〜H＋個数＋賞ごとの写真）／あとから編集（「編集」ボタンでフォームに読み込み→保存）／のこり個数の −＋／状態変更／削除（2回押し）
- 📍 お店を追加／編集／削除
- 📰 ニュースを追加／編集／削除
写真はアプリの中で自動で小さく（最大900px JPEG）してから保存。写真なしでもOK。

## データの保存先
- SQL実行前：**その端末の中だけ**（localStorage）。スタッフページの上に📱と出る
- SQL実行後：Supabase（☁️）。だれのスマホで開いても同じ内容、追加すると即反映
